# Birds biodiversity

Analysis of bird monitoring data from Martinique, 2014–2025: species richness,
recorded abundance, Shannon diversity and temporal trends.

## Authors

Mykhailo Mas, Adam Nolan

## Dataset

Source: Martinique Breeding Bird Monitoring, supplied workbook
`data/raw/Observations 2012-2025.xlsx`. The analysis covers observations from
2014 to 2025 and combines detection records with species and observation-point
references. The source workbook is kept unchanged.

## Run

```sh
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/run_notebook.py
```

The script executes and saves both notebooks in order, each in a fresh kernel.
Alternatively, open them in a Jupyter-capable editor, select `.venv`, and run all
cells in Notebook 1 followed by Notebook 2. Both support the project root and
`notebooks/` as working directories.

## Project structure

- `notebooks/01_data_preparation_and_indicators.ipynb`: cleaning, descriptive
  statistics, sampling effort, annual indicators and sensitivity checks.
- `notebooks/02_statistical_inference_and_trends.ipynb`: confidence intervals,
  trend models and selected-species analysis.
- `scripts/run_notebook.py`: executes both notebooks in order.
- `data/raw/Observations 2012-2025.xlsx`: source workbook, unchanged.
- `data/processed/`: cleaned detections, point surveys and route-year indicators.
- `results/`: exported descriptive and statistical tables.
- `figures/`: exported figures from both notebooks.

Generated CSVs and figures are excluded from Git and regenerated by running the
notebooks. Tables and figures are also displayed inside the notebooks.

All charts are generated directly in the notebooks using the same white-background
Matplotlib style. Standalone charts for slides 8–10 are saved alongside the other
figures (`richness.png`, `recorded_abundance.png`, `shannon.png`,
`point_surveys.png`, `routes.png`, and the two `*_distribution.png` files).
